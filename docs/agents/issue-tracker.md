# Issue tracker

Work is tracked in
[GitHub Issues for linvelive/frost-ecy-stat](https://github.com/linvelive/frost-ecy-stat/issues).
Specs, PRDs and tickets are issues in this repository; use `gh` for operations.

Keep the intended result, acceptance criteria and current checkpoint in the
issue body. GitHub owns status, assignees and dependency relationships. Record
the resolved outcome with evidence in a resolution comment.

A PR completing all acceptance uses `Fixes #<number>`. A partial delivery uses
`Refs #<number>` and leaves the issue open. Hardware acceptance needs hardware
evidence; host tests and builds alone do not close it.
